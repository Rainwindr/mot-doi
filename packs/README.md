# Thư mục gói nội dung

Mọi gói `.json` được ghi tên trong `danh-sach.json` sẽ được game tự nạp khi mở trang.

1. Thêm hoặc sửa một file `.json` trong thư mục này (xem `mau.json` và `HUONG-DAN-VIET-GOI.md`).
2. Ghi tên file vào `danh-sach.json`, ví dụ: `{ "files": ["mau.json", "mua-he.json"] }`
3. Bấm Commit changes. Đợi 1–2 phút rồi tải lại game.
4. Kiểm tra trong game: Cài đặt → Gói nội dung. Gói lỗi sẽ được liệt kê kèm dòng sai, các gói khác vẫn chạy bình thường.

Muốn tắt một gói: xóa tên nó khỏi `danh-sach.json` (hoặc bỏ tick trong Cài đặt).
